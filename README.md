# Tomalan
Tomalan is a mobile app developed in 2020 as the final project for the "Tecnología de Programación" course.

The app is designed as a game for pre-drinking gatherings with friends. It allows players to add as many participants and challenges as they want, in addition to the preloaded challenges. Each challenge has a difficulty level, and based on that, players either have to drink a certain number of drinks if they fail the challenge or can assign drinks to another player if they succeed.

Tomalan is available in both English and Spanish, depending on your phone's language settings. If your phone is set to any other language, the app will default to English. The app uses the GSON library to handle JSON files, which store all the strings for challenges and other text within the app.

You can download the Tomalan.apk directly from this repository.
